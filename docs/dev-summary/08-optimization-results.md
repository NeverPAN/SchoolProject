# 开发总结 8：阶段 6 结果 —— 双 GPU 与质量优化对照

> 基线见 [06-baseline-metrics.md](06-baseline-metrics.md)；方案依据与文献见 [07-related-work.md](07-related-work.md)。
> 本轮全部对照在隔离服务（18081）以应用内真实任务完成，资源采样为**全程**（提交→终态，15s 间隔）。

## 1. 双 GPU 并行（已采纳为服务配置）

实现：`COLMAP_GPU_INDEX` 环境变量（默认 "0"）→ SIFT 提取/匹配与 `patch_match_stereo` 显式传 `gpu_index`；进入检查点参数与任务清单 `resolved_params`。排队单元仍是"按图片分配"（COLMAP 原生多卡调度）。

**坑与解决**：隔离服务 worker 环境残留 `CUDA_VISIBLE_DEVICES=0`，CUDA 只见 1 卡，`gpu_index "0,1"` 直接崩溃（`Invalid CUDA GPU selected`）。解除该变量后双卡生效——这也是"为什么此前从未用上第二块卡"的答案。

### 同数据同参数对照（South 40 张，2000px，depth10）

| 配置 | 稠密 | 总时长 | GPU 利用 | 全程资源峰值 |
| --- | ---: | ---: | --- | --- |
| 1 卡（任务 #8，也复现基线 #7） | 1,727.3s | 32.4 min | GPU0 85%，GPU1 0% | 显存 1.8GB，RSS 7.0GB，磁盘 4.6GB |
| **2 卡（任务 #10）** | **868.2s** | **18.1 min** | 双卡各 ~75%，显存均衡 1.7/1.8GB | 显存 1.8GB，RSS 4.2GB，磁盘 4.5GB |

- 稠密加速 **1.99×**，总时长 1.79×；其余阶段不变。
- 质量等同性：点数差 0.4%（1,979,897 vs 1,971,774，浮点噪声），dense_cov 78.72%→78.75%，mesh_cov 65.75%→65.98%，支撑 99.34%→99.32%，外插 0.66%→0.68%——**在噪声范围内一致**。

## 2. 稠密 3000px 对照（South 40 张，双卡）

| 配置 | 稠密 | 总时长 | 点数 | 网格面数 |
| --- | ---: | ---: | ---: | ---: |
| 2000px 双卡（#10） | 868.2s | 18.1 min | 1.97M | 1,016,913 |
| **3000px 双卡（#11）** | 1,408.6s | **29.1 min** | **3.75M** | **1,300,437** |

关键结论：**3000px 双卡（29.1 min）比 2000px 单卡基线（32.4 min）还快**，且点数 +89%、网格覆盖 65.8%→68.2%、纹理细节肉眼可见提升（`data/phase3-optimization/job11-3000px-P1180165.png`）。代价：外插 0.66%→1.41%（+0.75pp，更密的点云让 Poisson 外插略多）、贴图 GLB 51→63MB、显存峰值 3.4GB/卡、磁盘 9.5GB。

**决策**：隔离服务默认稠密分辨率提升至 3000px（质量优先）；`fast` 预设与 2000px 仍是轻量选项。100 张规模的任务预计 95–100 分钟（任务 #13 实测值待补）。

## 4. Delaunay 图割网格（可行性试探，评估后不采纳）

`delaunay_mesher` 需要工作区布局修正（`fused.ply`+`fused.ply.vis` 放入 dense 根目录）后可运行：South 云 → 1,177,094 面（105s）。指标 vs Poisson depth10：

| 指标 | Poisson d10 | Delaunay |
| --- | ---: | ---: |
| 网格覆盖（面片口径） | 65.8% | **87.5%** |
| 点支撑 | 99.3% | 93.1% |
| 无支撑外插 | **0.66%** | 6.9% |
| P95 面心-点距 | 0.0150 | **0.0101** |

同视角渲染（[delaunay-vs-photo-P1180165.png](../../data/phase3-optimization/delaunay-vs-photo-P1180165.png)）：立面覆盖更满，但**大量自由空间飞面**（窗框、柱廊边缘的白色三角片）肉眼可见。另发现 **4.2.1 texturer 无法直接处理带顶点色的 Delaunay PLY**（`vector::_M_default_append` 崩溃；原始无色 PLY 可烘），需额外适配。

结论：覆盖↑但外插↑↑、飞面缺陷明显、贴图管线需改造——**不满足"质量不降"约束，不采纳**；文献路线记录于 [07](07-related-work.md)。
