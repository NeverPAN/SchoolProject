# 答辩视频录制指南（操作 + 分镜脚本）

目标：一条 8–10 分钟的答辩演示视频，覆盖"主流程 → 展示优化 → 区域提取 → 局部重建 → 网格补丁 → 关键数据 → 诚实边界"。主重建与区域提取使用候选站已完成结果，录制时不等待长任务；局部更新按真实数据展示守卫拒绝（无非重复增量点）与 South D 链已发布候选，明确区分场景。

## 一、录制方式（二选一，推荐 A）

### 方式 A：本机录屏 + 旁白（推荐，答辩观感最好）

1. 在本机建 SSH 隧道（三个站点都转发）：

```bash
ssh -N \
  -L 18507:127.0.0.1:18507 \
  -L 18487:127.0.0.1:18487 \
  -L 18497:127.0.0.1:18497 \
  <用户>@<服务器>
```

2. 本机浏览器打开 `http://127.0.0.1:18507/`，确认 `/version.json` 显示 `source_git_head`。
3. 录屏软件：
   - Windows：OBS Studio（显示器采集 1920×1080、30fps）或 `Win+G`；
   - macOS：QuickTime Player → 新建屏幕录制；
   - 旁白：OBS 直接配麦克风；QuickTime 可同时录麦克风。
4. 浏览器按 `F11` 全屏、缩放 100%、隐藏书签栏；关闭系统通知（录屏期间勿操作其他窗口）。

### 方式 B：零剪辑兜底（可由我生成）

Playwright 脚本化走查（自动点击 + 鼠标轨迹 + 逐页停顿），输出 WebM。没有旁白、鼠标路径机械化，适合作为"方式 A 翻车时的替补素材"或剪辑底板。需要时说一声即可生成。

## 四、录制前清理（一次性，执行前无需再动）

```bash
# 删除彩排期产生的探针/重复项目（保留「浏览器E2E-South」= 项目 2 作为证据现场）
curl -s -X DELETE http://127.0.0.1:18507/api/v1/projects/1 -H "Authorization: Bearer <token>"
curl -s -X DELETE http://127.0.0.1:18507/api/v1/projects/3 -H "Authorization: Bearer <token>"
```

`<token>` 用 `e2e_reviewer` 登录获取；删除只影响候选站演示库，不影响 18487/18497 验收环境。

## 五、录制技巧与常见断点

- **先走一遍不录的彩排**：按分镜表空跑一次，记下每步的真实点击位置；
- **每个镜头独立录**：OBS 按镜号分段录制（标记剪辑点），比一条长录像好剪十倍；
- 哈希对比镜头：终端字体调大（`Ctrl`+`+`），命令提前写好只贴回车；
- 下拉选照片：输入 `P1180177` 过滤后回车点选，比滚动稳定（录制时鼠标动作放慢）；
- 断点预案：任何页面加载失败 → `F5`；若候选站被占用 → `acceptance_env.sh status` 查看后重启；
- 素材兜底：`docs/integrated-acceptance-evidence/browser-e2e/` 有全流程 16 张截图，任一镜头翻车可用截图 + 旁白过渡。
