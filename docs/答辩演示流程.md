# 答辩演示：从基础重建到组合提速与展示优化

[项目总览](项目总览.md)解释每一轮的证据与取舍；本页是现场操作脚本。主线固定 ETH3D Bridge 100 张原片。预先打开下列模型页；端口转发、账号和启动方式见[版本管理](版本管理.md)。现场不等待 GPU 重建；用[真实上传及任务验收](phase2-acceptance.md)说明全链路，并用已校验的产物展示每轮迭代。

| 顺序 | 打开 | 讲解要点 |
| --- | --- | --- |
| 1 | `18082` 项目 2，模型 **#29** | 2000 px、单 A800，83.91 分钟。先看原照对应立面，再看点云、网格与贴图。 |
| 2 | 同项目 **#59**，或 `18469` 项目 1 **#5**（同字节） | 3000 px、双 A800，75.89 分钟。分辨率和卡数同时变化，不是纯双卡加速实验。 |
| 3 | `18469` 项目 1，**#17 → #22** | 同为双卡 3000 px 冷跑，组合改动使任务 73.70→48.00 分钟（−34.9%）。覆盖略降、贴图面率升高；不是单项参数收益。#17 是正式速度对照，不能用 #59 代替。 |
| 4 | 同项目 **#22 → #24**（#23 是对应网格） | 同一融合点云，Poisson trim 10→9，再贴图。上部投影近点像素 65,447→91,060，不是新增点云，也不是证实真实屋顶面积。先用单色/线框看孔洞和薄结构。 |
| 5 | 保持 **#24** 和相同视角，写实→原色贴图、**0 EV** | 用户目测更亮、观感更好；只去除有纹理材质的查看器灯光，不改变下载文件或几何。 |

**视角与离线备用。** 固定立面、屋檐和俯视位置；不同模型的「重置视角」按各自包围盒取景，并不等于严格同位姿。若用于定量截屏，使用共同源照片与各任务对应相机外参。`data/quality-check/job6-model29/model_29.glb` 和 `data/quality-check/job13-model59/model_59.glb` 为历史离线模型；#17/#22/#24 用验收站下载，按[冷跑归档](combined-benchmark-evidence/import.json)和[顶部归档](roof-audit-evidence/import.json)比对 SHA-256。将原色效果预录备用，因为普通 GLB 阅读器不会复现网站的模式切换。待小组记录：同姿势立面截图、屋檐线框图、#24 固定视角的模式切换短片、断网彩排。已有顶部投影叠图不等同于网页实拍。

2. 返回同一个 #24，演示「局部重建」选择三张经标定照片，打开既有任务 #15 和 #28；说明它是点云候选，不依赖 #27。现场可用已完成任务，不等待重跑。

见[局部平台验收](dev-summary/18-local-platform-review.md)。两个分支都不替换 #24，也不代表贴图网格拼接通过。后续截图及 #28 质量结论见[查看器与留出深度复验](dev-summary/19-viewer-and-platform-holdout.md)；「回父模型看选区」属于新版源码，不假定历史站点已有。

## 断网彩排清单（答辩前最后一晚执行）

目标：在无外网、无 GPU 环境的答辩机上把整个演示走一遍，只依赖[离线演示包](deployment.md#集成候选站部署3000-px-双卡隔离环境)与本清单。打包命令：

```bash
bash scripts/make_offline_package.sh --out /tmp/offline \
  --dist frontend/dist \
  --model <关键演示 GLB：写实/原色两版 + 区域裁剪版 + 局部点云候选>
```
