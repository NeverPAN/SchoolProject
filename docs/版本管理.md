## 从哪儿打开

历史服务不变。实验服务是独立运行包 `experiments-cd15eb0efa55`（基于 Git `75e378f`，含当时未提交的实验显示改动），容器回环端口 **18448**，建议本机转发 **18449**。查看 `/version.json` 核对运行包指纹；不要用 Git HEAD 推断运行中的代码版本。

```bash
ssh -N -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:18449:127.0.0.1:18448 <容器SSH别名>
```

保留原 SSH 跳板和端口配置。用 `experiment_reviewer` 登录 `http://127.0.0.1:18449/`，选择 **优化实验验收（项目 #1）**。明文测试口令见仓库外的私有 `../.demo-private/三个演示版本启动说明.txt`，或由有权限的成员读取实验包中的 `test-password`。实验项目已有的数据是导入归档，不是当前服务重新运行重建得到；此实例不启动 Worker 或 GPU。

```bash

cd "$R/backend"
export RECON_ENV_FILE="$R/runtime.env"
PY=$(<"$R/python-path")
```

这个后端为前端提供同一冻结包的 `frontend/dist`，读取独立 `app.db` 和 `data/`。保留这几个路径，不复制到旧实例。重建新副本时先在新目录构建前端、准备独立 `runtime.env`（SQLite、data、scratch 指向新目录）、执行 Alembic 到 `7b4d8f1ce921` 或兼容 HEAD，再建验收账号。明确创建 `experiment-runtime.marker` 后，用 `PYTHONPATH=<副本的 backend>` 运行 `scripts/import_experiments.py --runtime <副本目录> --owner <验收账号> --assets <仓库 data 目录> --catalog docs/gpu-benchmark-evidence/experiment-catalog.json`。导入依赖本地保留的真实产物，不把大文件或密码放入 Git。新副本需要重新记录模型映射和运行包指纹。
