旧版共用的启动步骤（仅在独立验证副本或批准的停机恢复窗口操作）：
  1) 用 git worktree add --detach <独立目录> <上述参考提交>，依选定提交安装依赖并构建 frontend/dist。
  2) 在新建的私有 .env 中设置 DATABASE_URL、DATA_DIR、SCRATCH_DIR、REDIS_URL、SECRET_KEY、RECON_MODE、RECON_USE_GPU、COLMAP_BIN；第二套另设 COLMAP_TEXTURER_BIN、COLMAP_GPU_INDEX=0,1、COLMAP_DENSE_MAX_IMAGE_SIZE=3000。
  3) 检查配置指向正确环境，准备批准的 Redis 队列；避免与另一环境共享 Redis DB/队列。在选定版本的 backend 目录中用其虚拟环境执行 python -m alembic upgrade head（只针对备份复本或经过批准的目标库）。
  4) 在干净的两个终端中设置相同的绝对 RECON_ENV_FILE，再分别运行：
       .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port <8000 或 18081>
       .venv/bin/python -m app.workers.rq_worker
  5) 请求 /api/v1/health 并核对 Worker 日志和模型下载；不要仅凭健康接口宣布版本恢复成功。备份和恢复细节见 docs/deployment.md。
