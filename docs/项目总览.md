# 项目总览：从单卡重建到 Bridge 局部更新

本项目把多视角照片转换为可在网页查看、可下载的点云、网格和照片贴图模型。Vue/Three.js 负责交互，FastAPI 管理项目、输入、版本和产物，Redis/RQ Worker 调用 CUDA COLMAP 完成重建，并保留阶段日志和检查点。架构细节见[系统架构](architecture.md)，全部资料见[文档目录](目录.md)。

## 答辩主线：同一个 Bridge 场景逐步展开

| 顺序 | 打开与对照 | 做了什么，得到了什么 |
| --- | --- | --- |
| 1. 2000 px 单卡 | `18082` 项目 #2，**#29** | Bridge 100 张原片，单 A800，83.91 分钟。作为质量修复后的历史起点，先看立面、三角面和贴图。[基线与 GPU 矩阵](dev-summary/11-gpu-resolution-benchmark.md) |
| 2. 3000 px 双卡 | 同项目 **#59**，或 `18469` 项目 #1 的 **B00/#5**（GLB 字节相同） | 同场景，双 A800、3000 px，75.89 分钟。分辨率和卡数一起改变，不能将这两次运行的时差都算作双卡收益。固定 2000 px 的双卡因果对照来自 South：稠密阶段 1727.32 → 868.19 s，约 1.99×。[归档与受控对照](dev-summary/11-gpu-resolution-benchmark.md) |
| 3. #22 组合提速 | `18469` 项目 #1，**C00/#17 → C01/#22** | 100 张、双卡、3000 px、两组各做一次冷跑。组合改为 PatchMatch 3 次、融合 16 线程、贴图从 0.125 档开始。73.70 → 48.00 分钟（−34.9%）；照片贴图面率 89.62% → 91.62%，同协议网格投影覆盖 96.55% → 94.19%。有取舍，不把组合收益归给其中一个参数。[冷跑报告](dev-summary/14-combined-cold-run.md) |
| 4. #24 保留更多上部网格 | 同项目 **C01/#22 → R01/#24**，**#23** 是配套网格 | 复用 C01 的同一份过滤点云，Poisson `trim` 10 → 9，再贴图。上部投影中有近点支撑的网格像素 65,447 → 91,060（+39.1%），照片贴图面率 91.62% → 87.83%。增量是**上部网格保留**，不是多算了点，也不是证明不可见屋面已恢复。[顶部排查](dev-summary/15-bridge-roof-audit.md) |
| 5. 同一个 #24 的原色贴图 | 不换模型、不换视角，从「写实」切到「原色贴图」，**0 EV** | 有照片纹理的材质不再受查看器灯光影响。用户反馈更亮、观感更好；不改变下载 GLB、几何或原照片中已有的阴影。[版本与预览说明](版本管理.md) |
| 6A. #24 之后：区域提取 | `18479` 项目 #1，**#24 → #27**；任务 #14 | 「框选区域」后按三角面中心选取现有网格。真实 HTTP/RQ 约 13 s，单独 GLB 有 5,223 面。这是裁剪导出，不会生成新几何。 |
| 6B. #24 之后：新照片局部重建 | 同站 **#24 → #28**；任务 #15 | 「局部重建」使用 3 张经标定和内容校验的新增原片，在验证范围内运行双 A800 深度计算和融合。约 3 分 31 秒，产物是独立 PLY：4,258,813 点，其中新增 543 点，不是贴图网格。 |

最后两项是从同一个 #24 出发的**并列功能**，不是 #27 再升级成 #28。用户反馈网页端操作无问题；该反馈不代替对新版字段、父版定位或特定步骤逐项验收。真实历史任务、日志和下载校验见[局部平台验收](dev-summary/18-local-platform-review.md)。#24 的 GLB 为 307,895 顶点、449,617 三角面；网格没有独立点图元，不能用「点数 0」评价几何质量。

后续[查看器与留出深度复验](dev-summary/19-viewer-and-platform-holdout.md)增加了提取结果回父版看选区；真实 #28 留出对照显示覆盖微增，但共同射线深度误差中位数略升，保留为点云实验。查看器改动未覆盖历史站点。

## 集成方向：从证据链到通用系统

上述模型是证据链。系统本身已按[集成系统验收标准](集成系统验收标准.md)改造：任意照片集可走冻结配置的主重建（含通用 speed 画像）、原色贴图以文件实测为准、区域提取带父链接与边界报告、任意新增照片可注册到父模型做局部融合，网格补丁仅在不变量通过时发布。进展见[集成系统迭代](dev-summary/20-integrated-system.md)；真实 GPU 端到端验收仍是发布前提。
